## Featured Projects

### Whybase

**An AI-powered database investigation agent.**

Whybase lets users investigate databases using natural language. Instead of manually exploring tables and writing queries, the system can reason about the database, form hypotheses, execute safe read-only queries, and return evidence-backed conclusions.

**Built with:**

`Node.js` `Express` `MySQL` `MongoDB` `Groq` `Electron`

### VeriMail

**A production-oriented multi-tenant email verification platform.**

VeriMail provides email verification infrastructure with organization isolation, API keys, RBAC, subscription plans, rate limiting, and verification analytics.

**Built with:**

`Next.js` `Express` `PostgreSQL` `Prisma` `Redis` `Tailwind CSS`
